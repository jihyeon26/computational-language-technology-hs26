## `data/processed/corpus_clean.parquet` (45,644 rows)

| column | description |
|---|---|
| `doc_id` | stable id: 'doc_' + first 10 hex chars of sha1(url) |
| `src_row` | index column of the raw Kaggle CSV (pointer to the source row) |
| `date` | publication date (datetime) |
| `month` | YYYY-MM |
| `quarter` | YYYYQn |
| `domain` | source (publisher) as given in the raw data |
| `url` | article URL |
| `title` | repaired title |
| `text` | fidelity text: repaired, NFC, boilerplate removed, paragraphs separated by a blank line |
| `tags` | dataset entity tags (list) |
| `n_paras` | paragraphs kept |
| `n_paras_removed` | paragraphs removed as boilerplate or empty |
| `n_chars` | characters of `text` |
| `n_words` | whitespace tokens of `text` |
| `en_sw_ratio` | share of English stop words (language heuristic) |
| `dup_cluster_size` | number of copies of this story before deduplication (1 = unique) |
| `is_api_reference` | True for API reference pages with code signatures (tier reference if they mention open models) |
| `om_tier` | open-models relevance tier: core / reference / mention / none |
| `om_score` | relevance score (Section 7.2) |
| `om_families` | open-model family ids mentioned (list) |
| `om_regions` | developer regions of the mentioned families (list) |
